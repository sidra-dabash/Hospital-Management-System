# نظام إدارة مستشفى Vivio

تطبيق ويب لإدارة عمليات المستشفى، مبني باستخدام Laravel 12 وPHP 8.2 وSQLite افتراضيًا، مع واجهة عربية متوافقة مع الجوال.

## المتطلبات

- PHP 8.2 أو أحدث، مع إضافات PHP التي يتطلبها Laravel وامتداد SQLite.
- Composer.
- Node.js وnpm.

## التثبيت والتشغيل محليًا

من مجلد المشروع نفّذ:

```bash
composer setup
php artisan serve
```

افتح `http://127.0.0.1:8000`. أمر `composer setup` يثبت حزم PHP وJavaScript، ينشئ `.env` ومفتاح التطبيق وملف SQLite عند الحاجة، ثم يطبق الترحيلات ويجهز الأدوار والأقسام.

لإنشاء حسابات وبيانات تجريبية محلية، نفّذ مرة واحدة:

```bash
php artisan db:seed --class=UserSeeder
```

حسابات التجربة المحلية تستخدم كلمة المرور `password123`:

| الدور | البريد |
|---|---|
| مدير | `admin@hospital.com` |
| طبيب | `ahmed@hospital.com` أو `mohamed@hospital.com` أو `sara@hospital.com` |
| مريض | `patient@hospital.com` |
| ممرض | `fatima@hospital.com` أو `mariam@hospital.com` |
| استقبال | `hossam@hospital.com` |
| محاسب | `karim@hospital.com` |

هذه الحسابات والبيانات للاستخدام المحلي والعرض فقط. لا تشغّل `UserSeeder` في الإنتاج؛ فهو يتوقف تلقائيًا عندما تكون البيئة `production`.

## الوظائف والأدوار

- **المدير:** إدارة المرضى والأطباء والأقسام والمواعيد والتقارير والفواتير.
- **الطبيب:** إدارة المرضى المرتبطين به، مواعيده، والسجلات الطبية المسموح بها.
- **الممرض:** الاطلاع على بيانات المرضى والمواعيد والسجلات الطبية.
- **الاستقبال:** إدارة بيانات المرضى والمواعيد دون الاطلاع على السجلات الطبية.
- **المحاسب:** الاطلاع على الفواتير وإدارتها.
- **المريض:** إكمال ملفه الشخصي، حجز المواعيد، والاطلاع على بياناته المرتبطة بحسابه.

## الاختبارات وبناء الواجهة

```bash
php artisan test
npm run build
```

## تجهيز بيئة إنتاج

- استخدم قاعدة بيانات إنتاجية مناسبة واضبط بيانات الاتصال في `.env`.
- اضبط `APP_ENV=production` و`APP_DEBUG=false`، ولا ترفع `.env` أو مفاتيح التطبيق إلى Git.
- أنشئ مفتاحًا فريدًا لكل بيئة، وشغّل `php artisan migrate --force` بعد أخذ نسخة احتياطية من قاعدة البيانات.
- شغّل `php artisan db:seed --class=RoleSeeder --force` لتجهيز الأدوار والصلاحيات. أضف حسابات الموظفين عبر واجهة الإدارة أو آلية نشر آمنة.
- ابنِ الواجهة باستخدام `npm ci && npm run build`، ثم نفّذ `php artisan optimize`.
- اربط خادم الويب بمجلد `public`، وفعّل HTTPS والنسخ الاحتياطي الدوري.

## ملاحظات البيانات

كل حساب مريض يجب أن يرتبط بسجل مريض. الحسابات القديمة التي لا تملك سجلًا مرتبطًا تُحوّل إلى صفحة إكمال الملف عند محاولة حجز موعد. يمكن للمدير ربط الحساب بسجل موجود من صفحة تعديل المريض.
