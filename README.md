# نظام إدارة مستشفى Vivio

تطبيق ويب لإدارة عمليات المستشفى، مبني باستخدام Laravel 12 وPHP 8.2 وSQLite افتراضيًا، مع واجهة عربية متوافقة مع الجوال.

## المتطلبات

- PHP 8.2 أو أحدث، مع إضافات PHP التي يتطلبها Laravel وامتداد SQLite.
- Composer.
- Node.js وnpm.

## التثبيت والتشغيل محليًا

من مجلد المشروع نفّذ:

```bash
composer setup
php artisan serve
```

افتح:

`http://127.0.0.1:8000`

أمر `composer setup` يثبت حزم PHP وJavaScript، وينشئ ملف `.env` ومفتاح التطبيق وملف SQLite عند الحاجة، ثم يطبق الترحيلات اللازمة لتجهيز المشروع.

لإنشاء حسابات وبيانات تجريبية محلية، نفّذ مرة واحدة:

```bash
php artisan db:seed --class=UserSeeder
```

حسابات التجربة المحلية تستخدم كلمة المرور:

`password123`

| الدور | البريد |
|---|---|
| مدير | `admin@hospital.com` |
| طبيب | `ahmed@hospital.com` أو `mohamed@hospital.com` أو `sara@hospital.com` |
| مريض | `patient@hospital.com` |

هذه الحسابات والبيانات مخصصة للاستخدام المحلي وعرض المشروع فقط.

## الوظائف والأدوار

- **المدير:** إدارة المرضى والأطباء والأقسام والمواعيد والتقارير والفواتير.
- **الطبيب:** الاطلاع على المرضى المرتبطين به، وإدارة مواعيده والسجلات الطبية المسموح بها.
- **المريض:** إكمال ملفه الشخصي، وحجز المواعيد، والاطلاع على بياناته ومواعيده المرتبطة بحسابه.

## الاختبارات وبناء الواجهة

لتشغيل الاختبارات:

```bash
php artisan test
```

لبناء الواجهة:

```bash
npm run build
```

## تجهيز بيئة الإنتاج

- استخدم قاعدة بيانات مناسبة لبيئة الإنتاج واضبط بيانات الاتصال في ملف `.env`.
- اضبط `APP_ENV=production` و`APP_DEBUG=false`.
- لا ترفع ملف `.env` أو مفاتيح التطبيق إلى Git.
- أنشئ مفتاح تطبيق فريدًا لكل بيئة.
- شغّل الترحيلات باستخدام:

```bash
php artisan migrate --force
```

- ابنِ ملفات الواجهة باستخدام:

```bash
npm ci
npm run build
```

- ثم نفّذ:

```bash
php artisan optimize
```

- اربط خادم الويب بمجلد `public`.
- فعّل HTTPS عند نشر النظام.
- حافظ على نسخة احتياطية دورية من قاعدة البيانات.

## ملاحظات البيانات

كل حساب مريض يجب أن يرتبط بسجل مريض حتى يتمكن من استخدام الوظائف الخاصة به، مثل حجز المواعيد والاطلاع على بياناته.

الحسابات القديمة التي لا تملك سجل مريض مرتبطًا بها يتم توجيهها إلى صفحة إكمال الملف عند محاولة حجز موعد.

يمكن للمدير ربط حساب المريض بسجل موجود من خلال صفحة تعديل بيانات المريض.
